# Общие типы GUI-протоколов v1

Все целые поля сериализуются little-endian. Указатели и внутренние структуры
процесса в IPC не передаются. Значение `0` зарезервировано как недействительное
для всех идентификаторов.

| Тип | Представление | Инвариант |
| --- | --- | --- |
| `ClientId` | `u64` | Живёт не дольше IPC-соединения |
| `DisplayId` | `u64` | Уникален до удаления выхода или перезапуска сервиса |
| `SurfaceId` | `u64` | Принадлежит создавшему IPC-клиенту |
| `BufferId` | `u64` | Принадлежит клиенту до destroy или отключения |
| `WindowId` | `u64` | Принадлежит создавшему клиенту |
| `Serial` | `u64` | Монотонно возрастает в рамках соединения |
| `Coordinate` | `i32` | Логическая координата в 24.8 fixed-point |
| `Dimension` | `u32` | Положительный размер в логических единицах |
| `Scale` | `u32` | Масштаб в 16.16 fixed-point, `1.0 = 65536` |

```text
Point     = { Coordinate x, Coordinate y }
Size      = { Dimension width, Dimension height }
Rect      = { Coordinate x, Coordinate y, Dimension width, Dimension height }
Color     = { u8 red, u8 green, u8 blue, u8 alpha }
```

## Форматы пикселей v1

| `PixelFormat` | Хранение одного пикселя |
| --- | --- |
| `XRGB8888` | B, G, R, неиспользуемый байт; непрозрачный |
| `ARGB8888` | B, G, R, A; premultiplied alpha |

Строки передаются как UTF-8 без завершающего NUL с отдельной длиной `u16`.
Максимальная длина заголовка окна — 256 байтов. Массив прямоугольников damage
содержит не более 64 элементов; пустой массив означает отсутствие damage, а
специальный флаг `FULL_DAMAGE` — повреждение всей поверхности.

Каждый запрос содержит `u16 protocol_version` и `u64 request_id`. Ответ
повторяет `request_id` и содержит `ErrorCode`. События изменения состояния
содержат `Serial`, позволяющий клиенту подтверждать конфигурацию и отбрасывать
устаревшее состояние. События завершения асинхронной операции могут вместо
этого повторять `request_id` операции. Полное wire-кодирование определено в
[базовом протоколе GUI](protocol-base.md).
