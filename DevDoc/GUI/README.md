# Графическая подсистема PUNos

Этот раздел принадлежит GUI-команде и является точкой входа в документацию
графического стека. Общесистемные механизмы остаются в своих каталогах и
подключаются только через публичные контракты.

## Состав

| Компонент | Ответственность |
| --- | --- |
| [displayserv](Services/displayserv.md) | Дисплеи, режимы вывода и показ готового кадра |
| [compositorserv](Services/compositorserv.md) | Поверхности, буферы, damage и композиция сцены |
| [windowserv](Services/windowserv.md) | Окна, фокус, размещение, z-order и маршрутизация ввода |
| [displaylib](Libraries/displaylib.md) | Адаптер системного графического backend для `displayserv` |
| [uilib](Libraries/uilib.md) | Клиентский API окон, поверхностей и UI-событий |

`Specification.md` сохраняет первоначальный продуктовый охват GUI. Нормативные
контракты сервисов и библиотек находятся в отдельных документах этого раздела.
При расхождении приоритет имеет специализированный документ компонента.

## Порядок запуска

```text
logserv
  ├── displayserv
  │     └── compositorserv
  │            └── windowserv
  └── IOserv ──────────┘
                         └── uilib / приложения
```

`IOserv` не является частью GUI: он публикует физические события. Выбор окна,
фокус и преобразование координат принадлежат `windowserv`.

## Правило границы слоёв

GUI может зависеть от публичных заголовков System Libs, `appframework`,
`ipclib` и IPC-контрактов системных сервисов. GUI не подключает внутренние
заголовки и не принимает владение их файловыми дескрипторами или состоянием.
