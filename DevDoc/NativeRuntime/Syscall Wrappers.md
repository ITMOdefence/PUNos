Обертки на системные функции, которые инкапсулируют библиотеки и пользовательский код от вызова системных служб на прямую.

Ниже зафиксирован минимальный ABI собственной libc для Linux x86_64. Эти типы,
структуры и константы определяются в заголовках проекта; системные заголовки
glibc не используются. Значения относятся именно к Linux x86_64.

### Типы и структуры ABI

| Наименование | Представление | Назначение |
| --- | --- | --- |
| `struct timespec` | `time_t tv_sec; i64 tv_nsec;` | Интервал или момент времени в секундах и наносекундах |
| `struct itimerspec` | `struct timespec it_interval; struct timespec it_value;` | Период и первое срабатывание таймера `timerfd` |
| `sigset_t` | Псевдоним `u64` | Битовая маска сигналов Linux x86_64 |
| `sighandler_t` | Указатель на функцию `void handler(int signum)` | Обработчик обычного сигнала |
| `struct sigaction` | `sighandler_t sa_handler; u64 sa_flags; void (*sa_restorer)(void); sigset_t sa_mask;` | Действие, устанавливаемое для сигнала |
| `struct stat` | `dev_t st_dev; ino_t st_ino; nlink_t st_nlink; mode_t st_mode; u32 st_uid; u32 st_gid; u32 __pad0; dev_t st_rdev; off_t st_size; i64 st_blksize; i64 st_blocks; u64 st_atime; u64 st_atime_nsec; u64 st_mtime; u64 st_mtime_nsec; u64 st_ctime; u64 st_ctime_nsec; i64 __unused[3];` | ABI-совместимые метаданные файла для `fstat()` |
| `struct sockaddr` | `sa_family_t sa_family; char sa_data[14];` | Базовое представление адреса сокета |
| `struct sockaddr_un` | `sa_family_t sun_family; char sun_path[108];` | Адрес Unix socket |
| `struct in_addr` | `u32 s_addr;` | IPv4-адрес в сетевом порядке байтов |
| `struct sockaddr_in` | `sa_family_t sin_family; in_port_t sin_port; struct in_addr sin_addr; u8 sin_zero[8];` | IPv4-адрес и порт |
| `struct in6_addr` | `u8 s6_addr[16];` | IPv6-адрес в сетевом порядке байтов |
| `struct sockaddr_in6` | `sa_family_t sin6_family; in_port_t sin6_port; u32 sin6_flowinfo; struct in6_addr sin6_addr; u32 sin6_scope_id;` | IPv6-адрес и порт |
| `epoll_data_t` | Объединение `void *ptr`, `int fd`, `u32 u32`, `u64 u64` | Данные, возвращаемые вместе с событием epoll |
| `struct epoll_event` | Упакованная структура: `u32 events; epoll_data_t data;` | Описание интересующих и полученных событий epoll |
| `errno` | Потоково-локальная переменная типа `i32` | Код последней ошибки wrapper; обновляется при возврате `-1` или `MAP_FAILED` |

### Сетевое взаимодействие через сокеты

Сетевые сокеты используют те же обертки: `socket()`, `bind()`, `listen()`,
`accept()`, `connect()`, `send()`, `recv()` и `shutdown()`. Для них в
`socket()` указывается `AF_INET` или `AF_INET6` вместо `AF_UNIX`, а в
`bind()` и `connect()` передаётся сетевой адрес.

| Обертка | Аргументы | Возвращаемое значение | Задача |
| ------- | --------- | --------------------- | ------ |
| `setsockopt()` | `int sockfd` — сокет; `int level` — уровень опции; `int optname` — имя опции; `const void *optval` — значение; `socklen_t optlen` — размер значения | `int`: `0` при успехе; `-1` при ошибке | Устанавливает минимальные параметры сетевого сокета, например разрешение повторной привязки адреса |

### Доступ к устройствам и управление ими

Файлы устройств открываются через уже описанные `open()`, `close()`, `read()`,
`write()` и `mmap()`. Для данной категории требуется одна дополнительная
обертка:

| Обертка | Аргументы | Возвращаемое значение | Задача |
| ------- | --------- | --------------------- | ------ |
| `ioctl()` | `int fd` — файловый дескриптор устройства; `unsigned long request` — команда устройства; `void *argp` — аргумент команды или `NULL` | `int`: зависит от команды; `-1` при ошибке | Передаёт устройству специальную команду: настройку экрана, камеры или устройства ввода |
