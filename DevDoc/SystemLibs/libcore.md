
## Описание

Базовая системная библиотека с общими типами, кодами ошибок и операциями для
проверки размеров. Не зависит от libc и других System Libs. Машинные и Linux
ABI-типы получает из публичного заголовка Syscall Wrappers; это зависимость от
контракта типов, а не от объектного кода wrappers.

## Текущий статус реализации

Контракт реализован полностью в `System/SystemLibs/libcore`. Готовы:

- публичный заголовок `<sys/core.h>` со всеми типами и константами из таблиц
  ниже;
- статическая библиотека `libpunos_core.a` с операциями `core_is_ok()`,
  `core_size_add()`, `core_size_multiply()` и `core_error_from_errno()`;
- compile-time проверки ABI (`tests/abi_compile.c`);
- runtime-тест всех операций (`tests/core_runtime.c`), который выполняется на
  хосте командой `make -C System/SystemLibs/libcore check` и внутри PUNos в
  QEMU как `/punos/bin/libcore-selftest`.

Библиотека не содержит неразрешённых символов: от Syscall Wrappers она
использует только заголовки типов и констант, но не их объектный код.
Решения, принятые при реализации, описаны в
`System/SystemLibs/libcore/README.md`.

## Имя библиотеки
`sys/core`
## Контракты

1. Публичный заголовок `libcore` подключает `<punos/syscall/types.h>` и не
   объявляет повторно `u8`–`u64`, `i8`–`i64`, `size_t`, `ssize_t`, `off_t`,
   `pid_t` и другие Linux ABI-типы. Все нативные библиотеки получают эти типы,
   собственные типы платформы и `ErrorCode` через `libcore`.
2. Операция, которая может завершиться ошибкой, возвращает `ErrorCode`.
3. Значения, создаваемые операцией, передаются через указатели `out_*`.
4. При возврате ошибки значение в `out_*` не определено и не используется.
5. `CORE_OK` — единственный код успешного выполнения.
6. `usize` и `isize` имеют размер указателя целевой платформы Linux x86_64.
7. System Libs преобразуют `errno` Syscall Wrappers в `ErrorCode` только через
   `core_error_from_errno()`, если их собственный контракт не определяет более
   точную контекстную интерпретацию.
8. После ошибки Syscall Wrapper библиотека сохраняет значение `errno` до
   любого следующего wrapper и передаёт сохранённое значение в
   `core_error_from_errno()`.

## Типы

| Наименование | Представление | Допустимые значения | Назначение |
| ------------ | ------------- | ------------------- | ---------- |
| `u8` | 8-битное беззнаковое целое | `0` … `255` | Байт и малые беззнаковые значения |
| `u16` | 16-битное беззнаковое целое | `0` … `65535` | Малые размеры и флаги |
| `u32` | 32-битное беззнаковое целое | `0` … `4294967295` | Идентификаторы и счётчики |
| `u64` | 64-битное беззнаковое целое | `0` … `18446744073709551615` | Размеры файлов, время и большие счётчики |
| `i8` | 8-битное знаковое целое | `-128` … `127` | Малые знаковые значения |
| `i16` | 16-битное знаковое целое | `-32768` … `32767` | Малые смещения |
| `i32` | 32-битное знаковое целое | `-2147483648` … `2147483647` | Коды завершения и общие знаковые значения |
| `i64` | 64-битное знаковое целое | `-9223372036854775808` … `9223372036854775807` | Смещения и большие знаковые значения |
| `usize` | 64-битное беззнаковое целое | `0` … `USIZE_MAX` | Размеры буферов и индексы |
| `isize` | 64-битное знаковое целое | `ISIZE_MIN` … `ISIZE_MAX` | Разности размеров и смещения в памяти |
| `size_t` | `u64` из Syscall Wrappers | `0` … `USIZE_MAX` | Размер объекта в ABI нативного userspace |
| `ssize_t` | `i64` из Syscall Wrappers | `-1` … `ISIZE_MAX` | Число переданных байтов или ошибка syscall wrapper |
| `intptr_t` | Псевдоним `isize` | `ISIZE_MIN` … `ISIZE_MAX` | Преобразование указателя в знаковое целое |
| `uintptr_t` | Псевдоним `usize` | `0` … `USIZE_MAX` | Преобразование указателя в беззнаковое целое |
| `pid_t` | `i32` из Syscall Wrappers | Положительные PID/TID, `-1` как результат ошибки | Идентификатор процесса или потока Linux |
| `mode_t` | `u32` из Syscall Wrappers | Биты прав и типа файла | Режим доступа к файлу или каталогу |
| `off_t` | `i64` из Syscall Wrappers | Смещение файла в байтах | Позиция и смещение в файле |
| `clockid_t` | `i32` из Syscall Wrappers | Константы `CLOCK_*` | Выбор источника времени Linux |
| `time_t` | `i64` из Syscall Wrappers | Число секунд | Секундная часть времени Linux |
| `socklen_t` | `u32` из Syscall Wrappers | `0` … `4294967295` | Размер структуры адреса сокета |
| `sa_family_t` | Псевдоним `u16` | Константы `AF_*` | Семейство адресов сокета |
| `in_port_t` | Псевдоним `u16` | Порт в сетевом порядке байтов | Номер TCP/IP-порта |
| `dev_t` | Псевдоним `u64` | Идентификатор устройства Linux | Поля устройства в `struct stat` |
| `ino_t` | Псевдоним `u64` | Идентификатор inode | Поле inode в `struct stat` |
| `nlink_t` | Псевдоним `u64` | Число жёстких ссылок | Поле числа ссылок в `struct stat` |
| `Bytes` | Структура: `u8 *data`, `usize size` | Блок байтов длиной от `0` | Невладеющее представление последовательности байтов |
| `f64` | 64-битное число с плавающей точкой IEEE 754 | Конечные числа, `NaN`, `+∞`, `-∞` | Вычисления с плавающей точкой |
| `bool` | 8-битное беззнаковое целое | `false`, `true` | Логическое значение |
| `ErrorCode` | Перечисление | Коды ошибок из таблицы констант | Результат операции, которая может завершиться ошибкой |

## Константы

| Наименование | Назначение |
| ------------ | ---------- |
| `NULL` | Нулевой указатель |
| `true` | Логическое значение истины (`1`) |
| `false` | Логическое значение лжи (`0`) |
| `USIZE_MAX` | Максимальное значение типа `usize` |
| `ISIZE_MIN` | Минимальное значение типа `isize` |
| `ISIZE_MAX` | Максимальное значение типа `isize` |
| `CORE_OK` | Операция выполнена успешно (`0`) |
| `CORE_INVALID_ARGUMENT` | Передан недопустимый аргумент |
| `CORE_INVALID_PATH` | Путь имеет недопустимый формат |
| `CORE_INVALID_STATE` | Операция недопустима в текущем состоянии объекта |
| `CORE_OUT_OF_MEMORY` | Недостаточно памяти |
| `CORE_NOT_FOUND` | Запрошенный объект не найден |
| `CORE_ALREADY_EXISTS` | Объект с таким именем уже существует |
| `CORE_PERMISSION_DENIED` | Недостаточно прав для выполнения операции |
| `CORE_IO_ERROR` | Ошибка ввода-вывода |
| `CORE_TIMEOUT` | Истёк timeout операции |
| `CORE_INTERRUPTED` | Операция прервана сигналом |
| `CORE_WOULD_BLOCK` | Операция потребовала бы блокировки |
| `CORE_UNSUPPORTED` | Операция не поддерживается |
| `CORE_OVERFLOW` | Результат не представим в целевом числовом типе |

Числовые значения `ErrorCode` входят в ABI: `CORE_OK` равен `0`, остальные коды
нумеруются подряд с `1` в порядке этой таблицы (`CORE_INVALID_ARGUMENT` = `1`,
…, `CORE_OVERFLOW` = `13`). Коды могут пересекать границы процессов через IPC
и журналы, поэтому существующие значения не перенумеровываются, а новые коды
добавляются только в конец. Размер `ErrorCode` — 4 байта.

## Операции

| Операция | Аргументы | Возвращаемое значение | Назначение |
| -------- | --------- | --------------------- | ---------- |
| `core_is_ok(code)` | `ErrorCode code` | `bool` | Возвращает `true`, только если `code` равен `CORE_OK` |
| `core_size_add(left, right, out_value)` | `usize left`, `usize right`, `usize *out_value` | `ErrorCode` | Складывает размеры без переполнения; при переполнении возвращает `CORE_OVERFLOW`, при `out_value == NULL` — `CORE_INVALID_ARGUMENT` |
| `core_size_multiply(left, right, out_value)` | `usize left`, `usize right`, `usize *out_value` | `ErrorCode` | Умножает размеры без переполнения; при переполнении возвращает `CORE_OVERFLOW`, при `out_value == NULL` — `CORE_INVALID_ARGUMENT` |
| `core_error_from_errno(errno_value)` | `i32 errno_value` | `ErrorCode` | Преобразует положительный код Linux errno в общий `ErrorCode`; не читает глобальный `errno` самостоятельно |

## Преобразование `errno`

| Linux errno | `ErrorCode` |
| --- | --- |
| `EINVAL` | `CORE_INVALID_ARGUMENT` |
| `EISDIR`, `ENOTDIR` | `CORE_INVALID_PATH` |
| `ENOENT`, `ESRCH`, `ECHILD`, `ENODEV` | `CORE_NOT_FOUND` |
| `EEXIST`, `EADDRINUSE` | `CORE_ALREADY_EXISTS` |
| `EPERM`, `EACCES` | `CORE_PERMISSION_DENIED` |
| `ENOMEM` | `CORE_OUT_OF_MEMORY` |
| `ETIMEDOUT` | `CORE_TIMEOUT` |
| `EINTR` | `CORE_INTERRUPTED` |
| `EAGAIN`, `EINPROGRESS` | `CORE_WOULD_BLOCK` |
| `ENOSYS`, `ENOTTY`, `EOPNOTSUPP` | `CORE_UNSUPPORTED` |
| `EOVERFLOW` | `CORE_OVERFLOW` |
| Любое другое значение из диапазона `1` … `4095` | `CORE_IO_ERROR` |

Значение `0` не является errno ошибки и преобразуется в `CORE_OK`. Отрицательное
или неизвестное значение не передаётся в эту операцию; при нарушении условия
она возвращает `CORE_INVALID_ARGUMENT`.

Неизвестным считается значение вне диапазона Linux errno `1` … `4095`
(`MAX_ERRNO` ядра; ту же границу Syscall Wrappers используют для распознавания
ошибки syscall). Итоговые правила:

| Значение | Результат |
| --- | --- |
| `0` | `CORE_OK` |
| `1` … `4095`, есть в таблице выше | Код из таблицы |
| `1` … `4095`, нет в таблице | `CORE_IO_ERROR` |
| Меньше `0` или больше `4095` | `CORE_INVALID_ARGUMENT` |
