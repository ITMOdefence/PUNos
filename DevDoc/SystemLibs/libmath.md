## Описание
Системная библиотека определяющая числовые операции.

## Текущий статус реализации

Контракт реализован полностью в `System/SystemLibs/libmath`. Готовы:

- публичный заголовок `<sys/math.h>` со всеми типами, константами и
  операциями из таблиц ниже, под теми же именами, что в этой спецификации
  (без префикса `math_` и без `ErrorCode` — единственная System Lib с такой
  формой контракта);
- статическая библиотека `libpunos_math.a`;
- compile-time проверки ABI (`tests/abi_compile.c`);
- runtime-тест всех операций, включая распространение `NaN` и границы
  округления (`tests/math_runtime.c`), который выполняется на хосте командой
  `make -C System/SystemLibs/libmath check` и внутри PUNos в QEMU как
  `/punos/bin/libmath-selftest`.

Библиотека не делает системных вызовов и не хранит изменяемое состояние.
`floor()`/`ceil()`/`round()` реализованы через побитовую работу с
представлением IEEE 754 (без обращения к отсутствующей в PUNos
soft-float библиотеке); `sqrt()` — через инструкцию `sqrtsd`; `sin()`/`cos()`/
`atan2()` — через x87 `FSIN`/`FCOS`/`FPATAN`. Решения, принятые при
реализации, описаны в `System/SystemLibs/libmath/README.md`.

## Имя библиотеки
`sys/math`
## Контракты

1. Все числовые операции используют типы `f64` и `bool` из `libcore`.
2. Углы в тригонометрических операциях измеряются в радианах.
3. При недопустимом числовом результате функция возвращает `NaN`.
4. `NaN` передаётся через арифметические операции без преобразования в число.
5. Библиотека не использует системные вызовы и не хранит глобальное изменяемое состояние.

## Типы

| Наименование | Представление | Допустимые значения | Назначение |
| ------------ | ------------- | ------------------- | ---------- |
| `f64` | Тип из `libcore` | Конечные числа, `NaN`, `+∞`, `-∞` | Основной числовой тип операций |
| `bool` | Тип из `libcore` | `true`, `false` | Результат функций проверки числа |

## Константы

| Наименование | Значение | Назначение |
| ------------ | -------- | ---------- |
| `PI` | `3.141592653589793` | Число π |
| `TAU` | `6.283185307179586` | Полный угол в радианах, `2 × PI` |
| `DEG_TO_RAD` | `PI / 180` | Коэффициент перевода градусов в радианы |
| `RAD_TO_DEG` | `180 / PI` | Коэффициент перевода радиан в градусы |

## Операции

### Базовые операции

| Операция | Аргументы | Возвращаемое значение | Назначение |
| -------- | --------- | --------------------- | ---------- |
| `abs(x)` | `f64 x` | `f64` | Возвращает модуль числа |
| `min(a, b)` | `f64 a`, `f64 b` | `f64` | Возвращает меньшее из двух чисел |
| `max(a, b)` | `f64 a`, `f64 b` | `f64` | Возвращает большее из двух чисел |
| `clamp(value, min, max)` | `f64 value`, `f64 min`, `f64 max` | `f64` | Ограничивает значение диапазоном от `min` до `max` |
| `floor(x)` | `f64 x` | `f64` | Округляет число вниз |
| `ceil(x)` | `f64 x` | `f64` | Округляет число вверх |
| `round(x)` | `f64 x` | `f64` | Округляет число до ближайшего целого |

### Геометрия

| Операция | Аргументы | Возвращаемое значение | Назначение |
| -------- | --------- | --------------------- | ---------- |
| `sqrt(x)` | `f64 x` | `f64` | Возвращает квадратный корень; для отрицательного `x` возвращает `NaN` |
| `hypot(x, y)` | `f64 x`, `f64 y` | `f64` | Возвращает длину вектора с компонентами `x` и `y` |
| `sin(angle)` | `f64 angle` | `f64` | Возвращает синус угла в радианах |
| `cos(angle)` | `f64 angle` | `f64` | Возвращает косинус угла в радианах |
| `atan2(y, x)` | `f64 y`, `f64 x` | `f64` | Возвращает угол в диапазоне `[-PI; PI]` |
| `degrees_to_radians(value)` | `f64 value` | `f64` | Переводит угол из градусов в радианы |
| `radians_to_degrees(value)` | `f64 value` | `f64` | Переводит угол из радиан в градусы |

### Проверки чисел

| Операция | Аргументы | Возвращаемое значение | Назначение |
| -------- | --------- | --------------------- | ---------- |
| `is_nan(x)` | `f64 x` | `bool` | Проверяет, является ли значение `NaN` |
| `is_finite(x)` | `f64 x` | `bool` | Проверяет, является ли значение конечным числом |
